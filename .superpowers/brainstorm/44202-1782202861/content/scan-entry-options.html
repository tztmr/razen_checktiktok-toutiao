第三版工作台：扫描入口放哪里更顺手？

这三种都已经去掉第二版的顶部大横幅、路径工具条、统计卡片和下面那组三栏面板。 主界面只保留“大检测台”，区别只在扫描入口的打开方式。

状态总览 / 在线 / 掉线 / 用时

右上按钮 + 右侧抽屉 推荐

扫描入口挂在表格顶栏右上角，点开后从右侧滑出抽屉。主工作台完整保留，视觉最干净。

优点

  • 最像专业工作台，不打断表格阅读
  • 路径输入、拖拽、扫描设置都能收进抽屉
  • 适合后续继续扩展高级扫描参数

代价

  • 第一次进入时入口相对更隐蔽一点
状态总览 / 在线 / 掉线 / 用时

右上按钮 + 居中弹窗

扫描入口也放在工作台顶栏，但打开后用居中弹窗完成路径输入和扫描。

优点

  • 入口直觉，弹窗适合一次性操作
  • 实现简单，页面结构最稳

代价

  • 会盖住表格核心区域
  • 后续参数一多，弹窗会显得拥挤
状态总览 / 在线 / 掉线 / 用时

表格底部操作抽屉

保持整页极简，扫描入口藏在表格底边，点开后从底部升起操作层。

优点

  • 页面最整洁，桌面感强
  • 横向空间利用高

代价

  • 不如右侧抽屉自然
  • 会挤压表格底部可视区域
